# Pipeline Map (interactive)

The **[interactive pipeline map](pipeline-map.html)** is the physics-first design contract for NEREIDS and the recommended starting point for understanding the analysis: the physics spine (resonances → Doppler → Beer-Lambert → time-of-flight → instrument kernel → counts), the four fitting modes run live on-screen, the data taxonomy, and the API contract the code is reconciled against.

It is a standalone HTML page (open it in a browser; it needs no server).
It is the single description of the physics NEREIDS implements, and it says plainly which parts are not implemented yet.
